# SpendWise Dashboard

A static, responsive financial dashboard built with HTML and CSS. It presents a monthly spending summary and six category cards with sample budget information.

## Project files

- `index.html` contains the dashboard structure, navigation, monthly summary, and category cards.
- `style.css` defines the color theme with CSS custom properties, Grid and Flexbox layouts, responsive breakpoints, dark-theme colors, and card hover/focus interactions.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

The layout becomes a single-column page below 768px. The dark theme follows the device's `prefers-color-scheme` setting.
